# Contributing to ASE-Lab

Thank you for your interest in ASE-Lab.

**Current stage:** project foundation. The codebase, contribution process, and license are still being defined. **Please discuss proposed code contributions before opening an implementation pull request.**

## Discussion and documentation

Suggestions, questions, and corrections to public documentation are welcome through the public repository's normal discussion channels, where enabled. Before submitting a change:

- Review [the vision](docs/overview/vision.md) and [the scope](docs/overview/scope.md).
- Keep proposed changes limited, factual, and aligned with the project's current maturity.
- Distinguish implemented behavior from design ideas.
- Do not include internal notes, personal data, secrets, or unlicensed third-party material.

## Code contributions

A formal code contribution and licensing policy will be added before general external code contributions are accepted. Public visibility of the repository should not be interpreted as an open-source license for its original contents.

## Review standards

Changes should have a clear purpose, understandable rationale, and appropriate validation. Architectural decisions are published only after review.
