# Vision and goals

**Status:** Public foundation · **Maturity:** Initial draft

## Problem context

LLM-based agents can support software engineering tasks, but reliable agentic systems require more than model prompts: they need explicit software boundaries, tools, execution controls, observable behavior, and a path for incremental improvement.

## Vision

Establish **ASE-Lab** as an extensible software engineering environment in which specialized LLM-based agents and supporting capabilities can be introduced gradually, without requiring a full platform to exist from the beginning.

## Mission

Design, implement, and evaluate small, meaningful pieces of a longer-lived agentic software engineering product. Use existing libraries and SDKs deliberately while preserving understandable project-owned responsibilities and extension points.

## Intended audiences

- Software engineers exploring agent-assisted workflows.
- Students and educators learning by analyzing and extending real agent systems.
- Future contributors investigating new tools, integration approaches, or specialized agents.

## Goals

1. Build reusable, maintainable software components with a clear role in the eventual product.
2. Understand agent behavior through architecture study, implementation, and tests.
3. Keep technology choices evidence-driven and replaceable where practical.
4. Support future educational extensions and potential empirical research without requiring them for initial delivery.

## Long-term possibilities, not promises

Software engineering agents for code analysis, coding, testing, review, and documentation; tool integration through standard protocols; human oversight; and eventually collaboration between independently developed agents.

## Success in the initial academic stage

An intelligible architectural rationale, a selected and bounded implementation problem, and at least one **working, tested software slice** that contributes to the long-term design. A complete end-user product is **not** the required outcome of this stage.
