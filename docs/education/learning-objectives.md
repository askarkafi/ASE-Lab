# Educational objectives

ASE-Lab originated in the context of a doctoral-level course on **Software Engineering in the Age of Artificial Intelligence**. The educational objective is to understand modern agentic systems through a real engineering effort, not just to demonstrate a model API.

## Potential learning topics

| Topic | Example of meaningful learning evidence |
| --- | --- |
| Agent runtime and loops | Analyze responsibilities and observable execution events |
| Tool calling | Build and test a project-owned tool; inspect invocation and results |
| MCP | Connect to a server or implement a small task-specific MCP server |
| Agent skills | Design and assess a reusable behavior/skill definition |
| Context engineering | Explore how information is selected, retained, or condensed |
| Planning and coordination | Explain whether planning is implicit, explicit, or delegated |
| Software architecture | Record boundaries, dependencies, trade-offs, and decisions |
| AI-assisted development | Review and verify changes produced with coding assistants |
| A2A / multi-agent systems | Consider or prototype later if the selected scope supports it |

**Not all topics are required in the first academic stage.** Topics will be chosen to fit the actual implementation slice and course objectives.

## Evidence-based learning

For each selected topic, aim to produce an explanation, a small implementation or experiment, tests or traces, and a short analysis of limitations. Educational usefulness is judged by the reasoning and verification, not by the number of technologies installed.
