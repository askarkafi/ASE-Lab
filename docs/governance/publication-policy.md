# Public publication policy

**Status:** Initial policy

The public **ASE-Lab** repository presents reviewed documentation and software releases. Exploratory work, drafts, alternative designs, and incomplete experiments may be maintained separately.

## Release principles

1. **Publish deliberate snapshots.** Public releases are selected and reviewed states of work, not a live mirror of every internal change.
2. **Review content and history.** Before publication, inspect the exact files, diffs, dependencies, license notices, generated outputs, and Git history included in the update.
3. **Avoid accidental disclosure.** Internal notes, credentials, private repository data, local artifacts, or sensitive execution traces must not be included.
4. **Make claims verifiable.** Document implemented behavior separately from plans and untested assumptions.
5. **Keep updates coherent.** Release notes should explain what was added, changed, and validated.
6. **Preserve attribution.** Respect third-party licenses and the authorship of contributions.

## What this means for contributors

Public issues, proposals, and pull requests are visible. Please do not put internal information or secrets in them. Contributions should be coordinated with maintainers while project licensing and contribution rules are still being finalized.

## Cadence

There is **no fixed publication schedule**. Updates will be released at meaningful project checkpoints.
